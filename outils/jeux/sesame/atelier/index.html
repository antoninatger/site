SÉSAME · ATELIER

Créez un jeu d'énigmes pour vos élèves : vos questions, vos photos ou vos textes, les bonnes réponses et un message de fin.

  1. Le type de questions : deux réponses (vrai/faux…), QCM, ou les deux
  2. Vos questions : à écrire, ou à importer d'un document Word
  3. Le message de fin que lisent les élèves
  4. Essayer, puis faire jouer : Lancer en classe, donner un Lien pour les élèves, ou Télécharger le fichier
Le style du jeu : à choisir maintenant ou plus tard, vos questions restent les mêmes

Première fois ? : cinq questions déjà écrites, à modifier pour faire les vôtres. Votre travail est gardé tout seul sur cet ordinateur, dans ce navigateur.

1. Le type de questions

Vos questions sont-elles toutes du même type ? Le nombre de questions se choisit dans la partie 2.

Combien de choix par question ?

Dans la partie 2, chaque question aura un menu « Type de réponse » : deux réponses, ou QCM de 2 à 4 choix. Les deux réponses ci-dessous servent pour toutes les questions qui ne sont pas des QCM.

Les deux réponses

16 caractères au plus. Un ou deux mots courts se lisent mieux, surtout avec beaucoup de questions.

2. Les questions (un levier par question)

A Combien de questions ?
questions (de 2 à 40). Les cases à remplir apparaissent en dessous.
ou, si vos questions sont déjà écrites dans un document :
B Remplissez chaque case
  1. Écrivez la question dans la zone claire, ou cliquez Mettre une photo.
  2. Type de réponse : « Deux réponses » (haut / bas, réglés dans la partie 1) ou QCM A-D. Pour un QCM, chaque choix a sa case, et la bonne réponse se coche ✓ sur sa ligne.
  3. Cliquez la bonne réponse : elle s'allume en couleur.

Au clavier : Entrée passe au choix suivant, Ctrl+Entrée à la question suivante, Alt+A à D (ou Alt+↑ / ↓) donne la bonne réponse.

Comment écrire le document pour l'import automatique ? (modèle Word à télécharger)

Télécharger le modèle Word : remplacez les questions d'exemple par les vôtres, enregistrez, puis cliquez « Importer des questions ».

Une question par paragraphe, les choix sur les lignes suivantes, la bonne réponse indiquée si vous voulez : 1. Quel réglage protège le mieux ton compte ? A) Un mot de passe court et facile B) La double authentification * C) Le même mot de passe partout 2. Une photo publiée peut-elle être effacée d'Internet pour toujours ? Réponse : non • Une question avec des choix A, B, C, D devient un QCM. • Une question sans choix devient un levier à deux réponses (haut et bas). • Choix acceptés : A) a. 1) - ☐ ○, en liste automatique de Word ou non, sur des lignes séparées ou côte à côte. • Bonne réponse : une étoile * ou (x) après le choix, une case cochée ☒, le choix en gras, souligné, surligné ou en couleur, une ligne « Réponse : B » (ou 2, oui, non, vrai, faux, ou le texte du choix), ou un corrigé à la fin (« Corrigé : 1-B ; 2-C »). • Un tableau avec des colonnes Question, A, B, C, D et Réponse marche aussi. • Fichiers acceptés : Word (.docx), PDF avec du texte, texte (.txt). Un PDF scanné en image ne peut pas être lu.

3. Le message de fin

Ce que les élèves lisent quand toutes leurs réponses sont justes. Pour le voir, cliquez « Essayer le jeu » puis « Voir le message de fin ».

4. Le titre du jeu

Le style se change tout en haut de la page, à tout moment : vos questions ne bougent pas.

Le lien pour vos élèves

Donnez ce lien à vos élèves (ENT, mail, cahier de textes…). Ils jouent directement sur le site, sur ordinateur, tablette ou téléphone : rien à installer.

Le jeu tient tout entier dans le lien : rien n'est enregistré sur un serveur. Si vous modifiez vos questions, refaites un lien.

Ouvrir pour essayer

Et maintenant ?

Votre jeu est dans le dossier Téléchargements de cet ordinateur : . C'est un seul fichier, qui s'ouvre dans un navigateur (Firefox, Chrome, Edge…).

  1. Sur l'ENT : déposez ce fichier dans un espace de la classe (documents, casier, cahier de textes). Les élèves le téléchargent, puis l'ouvrent d'un double-clic.
  2. Sur les ordinateurs de la salle : copiez-le dans le dossier partagé ou sur une clé USB, puis double-clic.
  3. Au tableau : ouvrez-le sur l'ordinateur du vidéoprojecteur et cliquez « Plein écran ».

Sur tablette ou téléphone, un fichier .html s'ouvre mal : préférez les ordinateurs. Pour modifier ce jeu plus tard, cliquez aussi « Sauvegarder mon travail ».
